# JNEP Learner 🇳🇵🇯🇵

**JNEP Learner** is a Japanese-learning and mock-test platform designed especially for Nepali learners who are preparing to study, work, or build their future in Japan.

The platform focuses on practical Japanese preparation through **smart mock tests, performance tracking, Japanese translation tools, and a simple learning experience**.

## 🌸 What is JNEP Learner?

JNEP Learner helps learners prepare for Japanese language examinations and improve their confidence through realistic mock-test experiences.

Instead of making learning complicated, the platform provides a focused environment where users can:

* Take Japanese mock tests
* Practice different difficulty levels
* Track their test performance
* Review Premium test answers
* Translate between Nepali, English, and Japanese
* Monitor their test history
* Upgrade to Premium for additional features

## 📝 Mock Tests

JNEP Learner provides three mock-test levels:

### Beginner Mock Test

* 10 questions per attempt
* 10-minute time limit
* Random questions from a 60-question bank
* Basic Japanese vocabulary, expressions, grammar, and reading

### Advanced Mock Test

* 15 questions per attempt
* 15-minute time limit
* Random questions from a 60-question bank
* More challenging vocabulary, grammar, reading, and situations

### Premium Mock Test

* 20 questions per attempt
* 20-minute time limit
* Random questions from a 60-question Premium bank
* More challenging Japanese vocabulary, grammar, reading comprehension, and situations
* Detailed results
* Answer review after completing the test
* Test history

Questions and answer choices are randomized to provide a different experience on each attempt.

## 🔄 Japanese Converter

The Japanese Converter supports translation between:

* English → Japanese
* Nepali → Japanese
* Japanese → English
* Japanese → Nepali

The converter is designed to use an online translation service through the website's server rather than exposing provider configuration directly in the browser.

## 📊 Dashboard

The JNEP Learner dashboard allows users to view their learning progress, including:

* Tests taken
* Average score
* Best score
* Recent test results
* Test history
* Premium subscription status
* Premium plan and expiry information

Previous test results remain available even after a Premium subscription expires.

## 🌐 Nepali & English Interface

JNEP Learner is designed for Nepali learners and supports both **नेपाली** and **English** interfaces.

The language preference can be used throughout the website, including navigation, buttons, test interfaces, results, plans, dashboard, converter, and other interface elements.

Japanese test content remains Japanese where it is needed for Japanese-language practice.

## 🎨 Design

JNEP Learner uses a modern Japanese-inspired visual style with:

* Sky blue
* Soft pink
* White
* Dark navy
* Rounded cards
* Clean typography
* Student-focused layouts
* Responsive design for different screen sizes

The website is designed to be professional and attractive without being overly complicated or childish.

## 🔐 Security & Payments

The project is designed with server-side processing for features that require protected configuration.

Payment integration is intended to work through supported payment providers, with payment verification performed by the server before Premium access is activated.

Sensitive payment credentials, API keys, and provider secrets should never be placed directly in frontend code.

The server starts using the `PORT` environment variable when provided, or port `8080` by default.
